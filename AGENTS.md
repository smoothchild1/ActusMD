# ActusMD Update Loop Protocol

*   **Before** starting any new work session, read `actus-md-workspace/IMPLEMENTATION_PLAN.md` to understand the current state.
*   **After** completing a phase, you must update the checkbox in `actus-md-workspace/IMPLEMENTATION_PLAN.md`, stage the files, commit the changes to the current feature branch, and push to origin.
*   Do not ask for permission to update the markdown plan; treat it as mandatory logging.
