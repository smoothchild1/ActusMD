# Project Constraints & Instructions

1.  **Architecture (Local Pilot):** Frontend (Expo/React Native), Backend (Node.js/TypeScript), State & Sync (Socket.io), Database (SQLite via Prisma), AI Models (Azure AI Speech, Azure OpenAI GPT-4o).
2.  **Git Protocol:** Never commit to `main`. Always work on a feature branch (e.g., `feature/stt-integration`). Commit frequently after every working sub-task.
3.  **Secrets Management:** Never commit `.env`. Always reference `.env.example` for required keys.
4.  **Model Aliases:** Use `--model opusplan` for architecture/planning commands. Use `--model claude-sonnet-5` for repetitive debugging and compilation fixes.
